# Kizomba AI DJ

AI-driven DJ-app for Kizomba, Ghetto Zouk, Semba och Afrobeats.

## Features

- **Mixer** - Dual deck med animerade waveforms, BPM-ring, volym och crossfader
- **AI DJ Console** - Naturligt sprak-prompts for setlist-generering, overgongsanalys och BPM-rad
- **Setlist** - Visuell energikurva, ladda latar direkt till decks
- **Katalog** - 12 latar med BPM, key, energi, genre-filter och sok

## Getting Started

```bash
npm install
npm run dev
```

## Tech Stack

- React 19 + Vite
- Canvas-baserade waveforms och energikurvor
- Camelot wheel-baserad key-kompatibilitet
